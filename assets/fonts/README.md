# Myanmar Unicode Font

ဤ folder ထဲတွင် `NotoSansMyanmar-Regular.ttf` ဖိုင်ကို ထည့်ပါ။

Project သည် `pubspec.yaml` မှတစ်ဆင့် အောက်ပါ family name ကို အသုံးပြုထားသည်။

```text
NotoSansMyanmar
```

Font မထည့်ထားလျှင် Flutter system fallback font ကို အသုံးပြုမည်ဖြစ်ပြီး Myanmar Unicode rendering သည် platform အလိုက် ကွာခြားနိုင်ပါသည်။ Production build မပြုမီ Myanmar Unicode font asset ကို မဖြစ်မနေ ထည့်ပါ။
